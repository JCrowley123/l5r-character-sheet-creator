# Release 8c device checks

Open the [Release 8c preview](https://966ad2ea.l5r-character-sheet-creator.pages.dev/) and use an exported character copy. The temporary Insight bonus is only for reaching the next rank on the test character.

| What to do | Pass looks like | iPhone Safari | Laptop Edge |
|---|---|---|---|
| Start with a disposable copy of a Rank 1 Kitsu character. In Manage → Identity, add the displayed Insight to Next Rank to Other Insight Bonus. | School Rank changes to 2. A dialog offers three spells, with Choose spells and Later. | Pending | Pending |
| Tap Later. Open Character check on Identity. Tap Choose Rank 2 spells. | The picker still offers three choices. It groups eligible spells by Element. A scroll already in Equipment is absent. | Pending | Pending |
| Add a spell, tap Later, save and reopen the character. | Two picks remain at Rank 2. Techniques and Equipment each have one entry for the chosen spell. Starting spells still have their own note. | Pending | Pending |
| Switch to Play, inspect the check, then return to Manage. | The note is readable in Play. The button returns in Manage. | Pending | Pending |
| Import a copy of an older character already at Rank 3. In Manage → Identity → Character check, open Review earlier rank spells. Pick Rank 2 and tap Later before confirming. | Opening the save grants no spells. Returning to the review shows an empty number field. | Pending | Pending |
| Select Rank 2, report one missing spell and confirm. Add that one spell. Save, then reopen. | Exactly one Rank 2 spell was available. There is no second claim for Rank 2. Rank 3 can still be reviewed separately. | Pending | Pending |
