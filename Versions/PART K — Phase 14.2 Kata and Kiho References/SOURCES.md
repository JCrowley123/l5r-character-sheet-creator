# Verified entry pages — Kata and Kiho

Verified against the owner's six source PDFs on 12 October 2026. All 17 Kata and all 73 Kiho currently in the app were located; no guessed or unresolved entries. The 19 distinct entry pages were rendered and visually checked for the printed heading, page number and column association. This table is the reviewable book-derived oracle; production lookup code is generated separately from it.

Use the **printed entry-start page**, not the PDF viewer's page number. Core Rulebook PDF pages are three higher; the elemental books are one higher. A continuation column or page does not change the entry-start citation. The existing catalogue identity Seven Storms’ Fist corresponds to the printed heading Seven Storm’s Fist (Book of Fire p.192); this release preserves the catalogue name and mechanics. All six Book of Void Kiho start on p.192, despite the older catalogue comment's broader pp.192–193 range.

Book extracts and page images remain in local research scratch space outside Git. Only names and citation metadata are carried into this release; the existing paraphrased rules text is unchanged. Skills, weapons, spells, Schools and other uncited records remain for subsequent batches.
