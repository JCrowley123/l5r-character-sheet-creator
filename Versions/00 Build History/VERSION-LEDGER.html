What the diff turned up

Three things worth knowing before reading the version-by-version account below.

One duplicate

l5rcharactersheet.html and the long “…dice roller.html” are byte-for-byte identical — same SHA-256, zero differing bytes. The long name is a descriptive rename of the same file. Safe to delete either copy.

A broken build

v07 swapped in a new coin-die icon but dropped the data:image/png;base64, prefix, so the coin renders as nothing. v08 is that same file with the 22 missing characters restored — the only difference between them.

A silent regression

v06 gave every Shugenja school affinity / deficiency data and printed it in the school info line. v07 stripped it out — and it has never come back. It is still missing in v13.

Where the weight went

Hand-written code plateaued after v04. Almost all growth since then is embedded artwork — die icons, ring watermarks, ring symbols — baked in as base64.

What lies beyond v13

The fourteen files supplied stop on 21 August. The project folder does not — ten further builds follow, nearly doubling the file again. None of them are analysed above.

FileBytesModified
Ordering is established by three independent signals that all agree: each file's own modified date, monotonic growth in size, function count, element IDs and embedded assets, and the base64 asset fingerprints — not by filename. All thirteen copies were hash-verified byte-identical to the files supplied. L525051.HTM, the odd name in the upload, is v04: an 8.3-style browser “Save page as” copy of that working version.
