AE2 revision 1 · how long the note stays

  • The note appears when the sheet makes the change: the first time an older character is opened, whether it came from a file or from the Characters list. (An import from the Characters list stores the file as it is, so the change happens when you first open it.)
  • The note is kept with the character, so it is still there if you close and reopen it, until you save the character yourself: Save, Save As New or Export JSON. Then it is gone for good.
  • Autosave does not count. The sheet autosaves a listed character a moment after it changes, so if autosave cleared the note, it could go before you had seen it.
  • The change itself happens only once: reopening never marks or adds the spells again.
  • The note says how it goes away, so nobody wonders why it is still there.
Recommendation: approve revision 1. It keeps the note only until you have saved the character yourself, as you asked. Saving it marks the note as read.

How it would work

  • Each School's own list. Sense, Commune and Summon for 19 Schools; Fuzake adds Path to Inner Peace; Yogo has all three once AE1 is in.
  • Every time a character is opened, from a file or from the Characters list, for every Shugenja School it has. When there is nothing to do, nothing is shown.
  • Held spells are marked as that School's spells, with their scrolls, exactly as ticking them in the review does today. Missing ones are added with their Spell Scroll, the same way the wizard adds them.
  • Never silent. One note per School names each spell and says "marked" or "added". The wording in the pictures is a draft.
  • A second Shugenja School's given spells are usually already held; they are credited to both Schools, as the review already does.
  • It is part of opening the character, so it is not an undo step. Choosing a School on the sheet is unchanged (the wizard already adds these spells).
Recommendation: approve. It is your proposal with the two conditions you agreed: each School's own list, and a note instead of a silent change.
AE3 · screen-only · hides controls, writes nothing

No XP box or × on automatic entries

The sheet adds School Techniques itself at 0 XP and takes them back itself when the School, Path or Rank goes. A × on them misleads: nothing records the removal, so the Technique comes back the next time the School's Techniques are applied. The same is true of a School's given spells.
