Resisting, combined: five versions

Each version puts together the three things agreed so far: buttons in the roll that ask what you are resisting, a list that follows the roll you opened, and your buttons beside the abilities. All five are drawn inside the real app with one character: Honour 6, Balance, Clear Thinker, Wary, Touch of the Spirit Realms (Tengoku), and a Missing Limb choice that is not a resistance.

Rank 1 · recommended

1 · Likely first, the rest one tap away

The roll shows buttons only for the effects expected on it. A small "Something else…" link brings the character's other effects. A roll with nothing expected shows one quiet line. Beside the abilities, the book decides: one named roll gets a button, like Spot ambush; otherwise a plain reminder.

For

  • The roll shows only what fits it, as you suggested. An Earth roll no longer offers Fear.
  • Nothing can be lost. A missing rule or an unusual call from the GM costs one tap, never the bonus.
  • Small. 225 px against 457 px today, and the Roll button stays on screen.
  • Honest about the rules: a button only where the book names one roll, so no "which roll?" question.
  • The ability's card says when it applies, which helps a player learn it.

Against

  • Two treatments beside abilities, a button or a reminder, which needs explaining once.
  • One quiet line stays on every ordinary roll.
  • What counts as "likely" depends on the rules table being right.
  • After "Something else…" the block grows to 300 px.
Rank 2

2 · Short list that shows what each adds

The same behaviour as version 1, drawn as a list. Because the list follows the roll it stays short, so each row can say which bonuses it brings before you choose. The Agility roll and the ability cards are as in version 1.

For

  • The strongest reminder: you see which abilities each effect brings before you tap.
  • The same safeguard as version 1.
  • A plain list, like the rest of the preview.

Against

  • Taller where it matters: 317 px on a Willpower roll, and the Roll button starts 103 px off the phone's screen.
  • The same words repeat on each row.
  • More to read at the moment the table is waiting for your roll.
Rank 3

3 · Strict by roll, a button on every ability

Your two ideas in their purest form. The roll shows only what fits it and nothing else, and every resistance ability has its own button. Where the book names no roll, the button asks which one.

For

  • The cleanest preview. A roll that resists nothing shows nothing (143 px).
  • Every ability is treated the same way: it has a button.
  • Closest to your original idea.

Against

  • No way out inside the roll. If the GM calls an unexpected roll, or the table lacks a rule, the bonus is not offered where the player is looking.
  • Abilities with no named roll need a "Which roll?" step: a new dialog and more taps.
  • Honour is not on this page, so its three effects have no button here.
Rank 4

4 · The page asks, the preview stays quiet

You start from the ability or from the Honour card. Their buttons open the roll with the effect already chosen. A roll opened the usual way shows only one quiet line. The ability cards are as in version 3.

For

  • The quietest preview: one line on every roll (193 px).
  • Each bonus is tied to where it comes from, including Honour.
  • The band says plainly what the roll is for.

Against

  • On a roll opened the usual way the effects are a tap away and easy to pass over.
  • You have to be on the right page first: Identity for Honour, Adv & Disadv for the rest.
  • Every button needs a roll to open, so the "which roll?" problem returns.
  • The most new controls on the pages.
Rank 5

5 · Everything shown, likely ones first

Nothing is ever hidden. Every effect the character has is on every roll; the ones expected on this roll come first and the rest are dimmed. Abilities get reminders only.

For

  • Nothing can be missed, and a wrong rule only changes the order.
  • The simplest to build.

Against

  • An Earth roll still lists Fear and Temptation, which you called wrong.
  • Buttons on every ordinary roll: 300 px, and the Roll button starts 86 px off the phone's screen.
  • It grows with every gift.
  • No way from an ability to its roll.

Recommendation: version 1

  • It is your ideas with one safeguard. The list follows the roll, abilities carry buttons, and "Something else…" means nothing can be lost.
  • It serves the player who forgets. The likely effects are in sight when the roll opens, the rest are one tap away, and the ability's own card says when it applies.
  • It is the smallest version that still reminds. 225 px against 457 px today, with the Roll button on screen. Versions 2 and 5 lose the button on the phone.
  • It does not pretend to know the roll. A button appears only where the book names one. Versions 3 and 4 have to ask "which roll?" for abilities like Clear Thinker.
  • It can borrow later. If the rules read finds one roll for Fear, the Honour card can take version 4's buttons without changing anything else.

What version 1 costs: two treatments beside abilities, and one quiet line on every ordinary roll. If you would rather have no line at all on ordinary rolls, that is version 3's preview with version 1's safeguard removed, and I would not recommend removing it.

  2. The rules read then fills in the real answers: which effects belong to which roll, and which abilities get a button.
