A11 · Explanatory text: gaps and one left edge

1 · Your Advantage card point. In Play the name and description are plain text, but each keeps its box's 10 px inner padding, so both start 10 px right of every line between them. This is measured the same on every Advantage and Disadvantage card, on the phone and the laptop. Proposed: in Play they lose that padding, so every line starts on one edge. In Manage they stay editable boxes, and text inside a box is inset by design, so Manage is unchanged.
