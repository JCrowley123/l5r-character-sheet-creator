1. The Core Insight: Monks = “Technique‑Driven Bushi with Kiho Slots”
Mechanically, L5R 4e Monks are:

Non‑spellcasters

Non‑skillcasters

Non‑social specialists

Technique‑driven martial characters

Kiho users, which behave like “spells but not spells”

So the cleanest way to integrate them is:

→ Treat Monks as Bushi for core mechanics (rolls, traits, rings)
→ Add a new subsystem: Kiho (parallel to spells, but simpler)
→ Add Monk Schools (parallel to Shugenja schools, but without affinities/deficiencies)
→ Add Kiho slots (parallel to spell slots, but with Monk‑specific rules)


2. Minimal Architectural Additions (the smart way)

Bushi

Restrictions on spells (Monks cannot cast spells)

Provide starting skills

C. Kiho System (the key addition)
Kiho behave like spells but with different rules:

Kiho Properties
Element (Air, Earth, Fire, Water, Void)

Mastery level

Activation type (Simple, Complex, Free)

Duration

Requirements (rings, traits, tattoos, school rank)

Kiho Slots
RAW: Monks prepare Kiho like Shugenja prepare spells, but with different limits.

You can reuse your spell slot system:

Slot count = Ring rank (same as spells)

Kiho prepared per element

Kiho activation consumes slot

Kiho refresh daily

Kiho Activation
This is where Monks differ:

Kiho activation is a roll, not a spellcasting check

Usually Ring + Trait

TN based on Kiho mastery

Some Kiho require Void expenditure

Some Kiho require tattoos or school rank

I already have:

Roll engine

Trait roller

Ring interactions

Void pip counter

So Kiho activation fits perfectly into your existing roll architecture.

D. Kiho UI
Reuse your spell UI layout:

Slot consumption

Duration tracking (optional)
