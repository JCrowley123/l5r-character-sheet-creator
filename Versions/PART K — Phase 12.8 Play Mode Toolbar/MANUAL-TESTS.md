# Manual tests — Phase 12.8 the old toolbar replaced

For the owner's iPhone (and a laptop if convenient), on the branch preview. About five minutes. If
the installed app shows the old version, close and reopen it once or twice first.

1. **The header.** Open a character from the Characters list. Under the name there is one row:
   **Characters**, **Save**, **⋯**, **Manage**, and the red seal. The old grey row of buttons
   (picker, Load, New Blank, Delete, Print, Export, Import) is gone. Try a character with a short
   name and one with a long name: the row looks the same.
2. **Characters.** Tap **Characters**: the Characters list opens. Open a character again from it.
3. **Save.** Change something (for example Notes, in Management), tap **Save**: a "Saved" line
   appears under the header. Reopen the character from the list: the change is there.
4. **The ⋯ menu in Play.** Tap **⋯**: a small menu opens under it, fully visible, with **Print**
   and **Export JSON**. Tap outside it: it closes.
5. **The ⋯ menu in Management.** Tap **Manage**, then **⋯**: the menu also has **Save As a copy**.
   Tap it: the character is copied (the list now shows both), and you are on the copy.
6. **Print.** From the ⋯ menu choose **Print**: the print dialog (or Safari's print sheet) opens.
   The header buttons should not appear in the print preview.
7. **Export JSON.** From the ⋯ menu choose **Export JSON**: on the iPhone the share sheet opens
   with the character's file, as it does from the Characters list.
8. **New characters.** There is no New Blank button any more: **Create New Character** and
   **Import JSON** on the Characters list are the ways in.

Report any step that behaves differently, with the device and browser.
