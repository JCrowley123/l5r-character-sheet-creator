# Printed weapon text — manual checks

Run on the live app after the merge, on a **copy** of a character (Manage → Save As a copy). These go into the
cycle's one combined checklist.

| # | Steps | Expected |
|---|---|---|
| W1 | Combat → Weapons: add a **Katana** from the list. Change its name to **Katana of the Unbroken Line, heirloom blade of the Kakita dueling house**. | On screen the field looks as before (one line). |
| W2 | Characters → the copy's ⋯ → **Export to PDF**, save the PDF, and open it. | On the weapons page the whole name and the whole Katana note are readable, wrapped onto more lines; nothing is cut off. |
| W3 | Close the print dialog and look at the Weapons table. | It looks as before; the name is unchanged. |
| W4 | iPhone: repeat W2 with Share → Print (or Save to Files). | As W2. |
