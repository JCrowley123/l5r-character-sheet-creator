# Official sheet comparison

The supplied five-page official character sheet was reviewed as a layout reference. The current export retains the eight existing L5RCM templates. It maps app data into the matching core and character-type pages; it does not copy all five official pages into every character export.

The follow-up redraws the damaged Bushi school-technique, Notes and Kata areas as vector labels and rules, preserving their existing field positions. Skill trait abbreviations have a legend, generated Miscellaneous guidance is removed, and wound totals and captions follow the actual exported character snapshot.

The official fifth page is a campaign summary: encountered characters, allies and enemies, visited locations, campaign notes and short/long-term objectives. The app has no equivalent structured campaign journal. Adding that whole page now would produce largely empty fields or require a separate feature. It remains a possible later journal/export extension; no invented data is added. Actual character notes and required overflow still export independently of the optional descriptions appendix.

Source: owner-supplied L5R 4th Edition Character Sheet.pdf, corresponding to Core printed pp.389–393. No new official PDF asset was imported into the distribution.
