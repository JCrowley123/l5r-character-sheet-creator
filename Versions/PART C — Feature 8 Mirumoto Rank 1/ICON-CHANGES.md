# Icon changes on top of Feature 8

This folder is **Feature 8 unchanged**, plus two icon patches. No game logic differs from
`PART C — Feature 8 Mirumoto Rank 1`: the Mirumoto build is spliced from the Feature 7 trunk
exactly as before and is byte-for-byte identical at that stage (sha `bfbbd19197c9fd81`).

## Build order

```bash
python splice_feature8.py      # Feature 8, from the Feature 7 trunk
python patch_stance_icons.py   # samurai artwork on three stance tiles
python patch_dice_icons.py     # gold d10 on the skill / attack / damage roll buttons
```

Each patch matches exact source text and fails loudly rather than corrupting the file, so a
second run errors with `ANCHOR [...]: 0 occurrences` — that means it is already applied.

## Dice icons

The skill roll, weapon attack and weapon damage buttons now carry the same faceted gold d10 the
floating manual dice tray uses, in place of the 🎲 emoji.

| Button | Class | Before | After |
|---|---|---|---|
| Skill roll | `.sk-roll` | 🎲 on a gold pill | gold d10, 30px |
| Weapon attack | `.wp-roll-btn` | 🎲 on a gold pill | gold d10, 30px |
| Weapon damage | `.wp-dmg-btn` | 🎲 on a gold pill | gold d10, 30px |

**Roll Initiative keeps its emoji.** It is neither a skill roll nor a weapon roll and was not part
of the request; it is the only 🎲 left in the build. Add `btnRollInitiative` to `ROLL_BUTTONS` in
`patch_dice_icons.py` to convert it too.

### The die is declared once

The d10 is about a kilobyte of SVG, and skill and weapon rows are generated by `makeSkillRow()` /
`makeWeaponRow()` — pasting the markup into those templates would put a full copy in every row, so
a character with fifty skills would carry fifty copies of the same geometry.

Instead the die is declared once as an `<svg><symbol id="iconD10">` beside the floating tray
button, and each roll button carries `<use href="#iconD10">`. Verified in the built page: **1
symbol definition, 3 `<use>` references.** The custom properties (`--gold`, `--gold-soft`, …)
still resolve through `<use>`, so the die stays in the sheet's palette and will follow any future
theming.

### Why the gold pill went

`.dice-btn` put a gold background behind the emoji. The die is itself gold, so leaving the pill
would have rendered a gold shape on a gold field. `.dice-btn.d10` drops the background, border and
padding; hover and press use the same scale transforms as `.dice-picker-die`, so every die on the
sheet behaves identically.

### Size

30px. Tested at 26 / 28 / 30 / 32 — none overflow the weapon roll-cell or the table, and the row
height is unchanged at 73px either way, so 30 was chosen for legibility of the facets and the
"10". `DIE_PX` at the top of the patch changes it.

tiles carry an icon — is unchanged and still enforced. That change belongs to the stance artwork,
not the dice.
