Cycle 7a · Your phone checks

25 October 2026. Ten checks for Rank/points, resistance and the original-sheet PDF.

Release pending. The build passed local QA twice. It has not been merged or checked live. Use this guide after the exact candidate has been made available on your phone; the existing live Release 6a cannot pass the new checks.

Before you start

  1. Keep an exported backup of your real characters. Use a disposable test character for these checks.
  2. After release confirmation, open the app in Safari and load the confirmed version. Record the version below. Do not clear your browser storage.
  3. Use Management when a step asks you to edit a Rank. The nine pips set the remainder; Points +/− changes the full points count.
  4. Choose Pass, Fail or Not run for each check. Add the step number and what you saw when something differs. A screenshot is helpful for layout problems.
  5. Use Download results when finished and send that file back. Browser saving is only a convenience; it may be unavailable for a local file.


A1 · Phone controls

  1. Open a disposable test character and enter Management.
  2. Find Honour, Glory, Status and Taint. Hold the phone upright.
  3. Check the Rank controls and the nine numbered pips; then rotate the phone and check again.

Expected: All nine pips stay together on a separate row on a narrow screen. Text and buttons remain readable and tappable.

Record result ↓

A2 · Honour carries and borrows immediately

  1. In Management set Honour Rank to 6 and use pip 9 for nine points.
  2. Use the Points + button once.
  3. Use the Points − button once.

Expected: The score goes from 6.9 to 7.0, then back to 6.9. No recognition button is needed.

Record result ↓

A3 · Recognition by your lord

  1. Set Glory Rank to 6 and points to zero. Use Points + nineteen times.
  2. Check the approved Rank is still 6, with 19 pending points.
  3. Press Recognition by your lord. Repeat with Status if convenient.
  4. Leave Management and confirm the recognition action is unavailable there.

Expected: Recognition converts 6 + 19 into Rank 7 and 9 points. Rank-based eligibility uses the approved Rank, not unrecognised points.

Record result ↓

A4 · Losses apply now

  1. Set Glory Rank to 6 with zero points.
  2. Press Points − once.
  3. Repeat for Status.

Expected: Each becomes Rank 5 and 9 points immediately, without recognition.

Record result ↓

A5 · Imperial Scion threshold

  1. Use a test character eligible for Imperial Scion apart from Status. Set approved Status to 3.
  2. Accumulate 10 pending Status points and inspect Imperial Scion eligibility.
  3. Recognise those points in Management, then inspect eligibility again.

Expected: Pending points do not satisfy Status Rank 4. Recognition makes the Status condition pass; any other prerequisite still applies. If no suitable fixture is available, leave Not run.

Record result ↓

A6 · Taint and growth preview

  1. Set Taint to Rank 0 and one point. Open the growth check.
  2. Check Earth and TN 5, with Jade Petal Tea unticked. Tick it and inspect the +2k2 change.
  3. Cancel the preview and confirm Taint is unchanged. Reopen it and check tea starts unticked.
  4. If convenient, check Rank 1 and Rank 4 previews.

Expected: Rank 0 with points is Seeds of Darkness. Level 1 uses TN 10 and Level 4 TN 25. Cancellation adds nothing. Only choose tea when the character drank it daily.

Record result ↓

A7 · Honour on resistance

  1. Set Honour to Rank 6 with nine points. Open an ordinary Trait/Skill roll preview used to resist Fear, Intimidation or Temptation.
  2. Check the Honour resistance option starts unticked. Select it and inspect the flat modifier.
  3. Close and reopen the preview.

Expected: It adds +6, not +6.9 or +7, and starts unticked again. Use a character without Failure of Bushido (Honor) or another overlapping resistance bonus for this simple check.

Record result ↓

A8 · Save and reopen

  1. Set recognisable values: Honour 6.9, Glory Rank 6 with 19 pending points, and Taint 0.3.
  2. Save/export a backup using the app’s normal character saving workflow. Close and reopen the test character.
  3. If you have an untouched pre-7a character backup, open a copy and inspect any one-time discrepancy notice before saving it as a new copy.

Expected: New values survive reopening. On an old save, Honour follows the old Points score; Glory/Status keep the old approved Rank and the fractional points. Keep the original backup. If no old backup exists, record that migration was not checked.

Record result ↓

A9 · Original-sheet PDF

  1. Give a test character an obvious name, for example Sairyū PDF check, and known traits/skills.
  2. From Characters, choose Export to PDF for that character and open the saved result in Safari/Files.
  3. Compare the name, rings, skills, armour and school information with the character. Check a character with many skills or long notes if available.
  4. If using Isawa or Chuda, check the chosen affinity/deficiency appears on the shugenja sheet.

Expected: The original L5RCM sheet design is used, macrons remain readable and extra entries continue on added pages. The PDF shows the selected character. Current wounds follow this app’s rules; R5’s wound overhaul is still future work. The PDF is a static sheet, not an editable character save.

Record result ↓

A10 · Ordinary printing and export feedback

  1. In Safari, try the existing ordinary Print action and cancel the print dialog.
  2. Try PDF export again and note any error, delay or failure to open/share the file.
  3. If you also use the home-screen app, try PDF export there separately and describe the result in Notes.

Expected: Ordinary Print still offers the webpage layout. Cancelling leaves character data intact. Record actual Safari/home-screen behavior; do not infer a pass from desktop QA.
