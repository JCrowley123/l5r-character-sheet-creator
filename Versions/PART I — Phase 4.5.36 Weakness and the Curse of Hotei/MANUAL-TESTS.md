# Manual checks — Weakness and the Curse of Hotei (iPhone Safari)

Open the deployed sheet twice first (the first open after a deploy shows the previous build). Use a new character in
Manage mode with Strength 3 and Perception 3.

| # | Do this | Expect |
|---|---|---|
| W1 | Disadvantages → add **Weakness** → Choose… | Eight Traits offered; pick Strength. The row reads "Strength 3 counts as 2." and the cost box 6 |
| W2 | Look at the Water card | The Strength box still says 3, with "Counts as 2 (Weakness)" under it; the Water Ring shows 2 with "Lowered from 3 (Weakness)" |
| W3 | Tap the Strength label, then Cancel | The preview's button reads **Roll 2k2** |
| W4 | Insight (Identity card) before and after W1 | The same Insight points |
| W5 | Add a second Weakness row → Choose… | Strength is greyed out ("already lowered by another Weakness") |
| W6 | Set Reflexes 3, Awareness 3; Weakness on Reflexes | Combat card: Base TN 15, Initiative uses 2 for Reflexes |
| H1 | Disadvantages → Seven Fortunes' Curse → Hotei; Void Points 3 | The row says the Void card takes 2 points at once; the Void card shows "Spend Void: For a Technique or Advantage (Hotei's Curse: 2 points)" |
| H2 | Tap that button | Void Points 3 → 1 |
| H3 | Tap a blank Void pip | Void Points back to 3 (both at once) |
| H4 | With 1 Void Point | The button is greyed out; holding it says it needs 2 |
