# Manual checks — Spell Names Match the Books (iPhone Safari)

Open the deployed sheet twice first (the first open after a deploy shows the previous build).

| # | Do this | Expect |
|---|---|---|
| N1 | Search → Spells → type `Fill the Emptiness` | **Fill with Emptiness**, its row reading "… Formerly Fill the Emptiness", **Core Rulebook p.196** |
| N2 | Search → Spells → type `Enticing Dance` | **Enticing Dance of the Flame**, **Core Rulebook p.182** |
| N3 | Open a character saved before this release that has either Spell | It loads, shows the name it was saved with, and its Cast button works |
| N4 | On a Shugenja who can learn Void 4 Spells, buy the scroll in Equipment → Spell Scrolls | It is listed as "Spell Scroll — Fill with Emptiness" and unlocks the Spell |
