# Campaign Wound Multipliers

Healthy is Earth ×5; each later threshold adds Earth × the selected multiplier. Core Rulebook printed pp.82 and 84. Default ×2; Management offers ×2, ×3, ×4, ×5 or one positive whole-number custom value. Wounds taken are preserved. Existing wound Advantages and Disadvantages wrap the corrected core.

The arithmetic is independent of the replaceable picker. Character save format advances from 6 to 7; old records gain ×2 when opened or exported. Invalid current-format values refuse loading before changing the character. The switch is CAMPAIGN_WOUNDS_ENABLED.
