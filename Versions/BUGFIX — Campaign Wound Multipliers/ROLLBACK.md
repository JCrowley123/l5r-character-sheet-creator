# Removal

Use qa/remove-phase.py on an external scratch copy of the Phase 0 source tree, after removing later releases through the removal-chain registry. Never run it on the live source tree. It removes the three owned fragments and manifest entries plus the wound-core and wound-seam marked blocks. qa/test-removal.py proves exact predecessor bytes and refusal safeguards.

No existing wound-entry wrapper is replaced. Removing this layer restores the preceding arithmetic and format chain. Format-7 saves are intentionally refused by the older app, so retain an older save or use a deliberate conversion rather than silently losing a campaign setting.
